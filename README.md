# Daffa Fazly Rashidan — Portfolio

Personal portfolio of **Daffa Fazly Rashidan**, a Data Science graduate from Universitas Negeri Surabaya.

This portfolio presents selected works across data analytics, machine learning, business intelligence, data visualization, and digital product development.

## About

I work with data from raw datasets and ETL processes to analysis, visualization, machine learning models, and decision-ready insights.

My approach focuses on turning data into information, information into understanding, and understanding into meaningful decisions.
